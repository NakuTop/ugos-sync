# UGOS Sync

原生 macOS 状态栏应用，让已有的绿联 NAS 同步引擎脱离完整客户端界面运行。

状态面板使用 AppKit `NSPopover` 与 SwiftUI，继承 macOS 的系统材质；macOS 26 使用系统玻璃效果。查看等待上传、接收的文件，选择本地目录与 NAS 目标目录，并配置单向或双向同步。

## 已实现

- 独立的引擎监督进程、NAS 心跳进程和状态栏界面；退出界面不会停止后台。
- 登录后自动启动，进程故障重启；心跳每 8 秒发送，断线后退避重连。
- 默认防止系统空闲睡眠，显示器仍可熄屏。关机、注销、手动睡眠或断网期间不能传输本地文件。
- NAS 用户名与密码登录、安全输入框、恢复已保存会话。同步只需登录 NAS 一次；绿联云设备查找是收起的可选入口。
- `NSOpenPanel` 本地目录选择，实际 NAS 根目录与子目录浏览，创建前检查 NAS 写入权限。
- 本地到 NAS、NAS 到本地、双向目录映射；拒绝重叠目录；配置失败后回读，避免误删已经提交的映射。
- 引擎状态、队列及暂停状态的实际读取；读取失败不会显示“全部同步完成”。

## 引擎与许可证

**MIT 许可证覆盖本仓库自己编写的控制程序，不覆盖绿联的厂商同步引擎。** 本仓库不发布厂商二进制、反编译代码、账号数据、证书、数据库或工作文件。安装时从你自己已经安装的官方客户端复制引擎，验证原始 SHA-256 与代码签名，复用已有配置和同步身份。

当前版本需要先在官方客户端初始化一个同步配置。它不是重新实现的、完全不依赖厂商引擎的 Syncthing 分支。

## 本地构建与安装

需要 macOS 13 或以上、Xcode Command Line Tools 和 Python 3。当前实机验收为 Apple Silicon / macOS 26。程序是本地构建的 ad-hoc 签名，尚未做 Apple 公证。

```sh
swift test
scripts/build.sh
```

首次配置：打开官方绿联客户端，登录自己的 NAS 并初始化同步。捕获已有引擎参数到私有目录，过程中不打印凭据：

```sh
python3 scripts/capture_engine.py --work-folder "$HOME/path/to/your/work"
python3 scripts/install.py --settings "$HOME/Library/Application Support/UGOSSync/engine-settings.json"
```

安装到 `~/Applications/UGOS Sync.app`，在当前用户的 LaunchAgents 中注册引擎、心跳和界面。然后退出官方客户端，在 UGOS Sync 设置中登录 NAS，选择本地目录和 NAS 目标位置。以后不用打开完整绿联客户端。

**不要打开两个引擎来访问同一个配置目录。** 监督进程发现端口已有监听时会等待；已有第三方监督服务需先停用。安装器可用重复的 `--replace-agent LABEL` 参数明确备份并停用旧的 LaunchAgent；不修改系统服务。

如果已经拥有私有引擎设置，可直接给安装器传入其路径。升级前请退出状态栏界面。安装器在私有目录保存此前版本与服务配置的备份。

## 登录与隐私

- 不保存密码。NAS 会话令牌存放在 `~/Library/Application Support/UGOSSync`，目录权限 `0700`、文件 `0600`，供后台恢复连接。
- 可选绿联云 OAuth 会话保存在钥匙串。它用于查找绑定设备，不是同步的第二个必填登录。
- 当前 NAS 文件接口要求 HTTPS，使用系统证书校验；认证请求不跟随重定向。
- 普通 NAS 文件接口、引擎代理、WebSocket 各自使用不同的认证方式；详见 [协议说明](docs/PROTOCOL.md)。
- 不上传遥测、凭据或工作文件到开发者服务。同步数据目的地为用户配置的 NAS。
- `1003` 是厂商定义的密码验证拒绝；程序不会自动重试密码。OTP／验证码的交互尚未完整实现，当前不支持这类账户的首次密码登录。

## 验证边界

已实测：官方 GUI 退出后的独立传输、文件修改、后台重启后恢复、新目录映射，以及从 NAS 下载回来的文件内容与本地 SHA-256 一致；原生目录浏览与状态面板可操作。NAS 密码登录也完成了用户实机确认。

测试与发布记录见 [验收记录](docs/VALIDATION.md)。短时验收不代表已经做过连续 24 小时耐久测试。可选绿联云密码登录／设备发现、OTP、所有 NAS 固件、Intel Mac 和大型目录尚未覆盖。云端只见 NAS 上已同步的副本；Mac 关闭时不会产生新的本地同步。
