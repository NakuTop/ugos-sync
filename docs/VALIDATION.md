# 实机验收

验收时间：2026-10-14 至 2026-10-15（Asia/Shanghai）。环境：Apple Silicon、macOS 26.5、官方桌面客户端 1.20.0；只使用自己账户下的 NAS 和专用验收文件。

| 项目 | 结果 |
| --- | --- |
| 原生 NAS 密码登录 | 用户在安全输入框完成，形成新的独立会话；受保护的目录和引擎接口可读 |
| 本地目录选择 | `NSOpenPanel` 实际选择专用验收目录 |
| NAS 目录选择 | 读取实际个人／共享根目录，展开子目录并选中目标位置 |
| 界面创建映射 | 点击创建后，两端存在相同的新目录 ID |
| 界面暂停／恢复 | 专用验收任务两端状态更新成功，保留其他字段 |
| 官方 GUI 退出后传输 | 新增文件从 NAS 下载回来的字节与本地相同 |
| 已有工作映射的修改及后台重启 | 修改文件在后台重启后同步，下载字节与本地相同 |
| 新界面映射文件修改 | 下载字节相同，SHA-256 见下方 |
| 心跳重连 | 控制关闭连接，实际出现 online → reconnecting → online |
| 会话续期 | NAS 接受认证的续期请求，私有会话可保存恢复 |
| 防止空闲睡眠 | `pmset -g assertions` 出现本守护进程的 PreventUserIdleSystemSleep 断言 |
| 原生状态面板 | 实际打开 AppKit popover，检查系统材质、完成状态和设置入口 |
| 临时配置清理 | 移除本次生成的两条验收映射；前后原有两端目录配置精确相同，保留物理验收文件 |
| 测试 | `swift test`：12 项，0 失败 |
| 构建与签名 | release 构建通过，应用及两个后台程序 ad-hoc 签名验证通过 |
